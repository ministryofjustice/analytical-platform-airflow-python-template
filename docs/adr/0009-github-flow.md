# 9. GitHub Flow

Date: 2026-02-24

## Status

Accepted

## Context

There has not been an explicitly defined branching strategy for the project.

## Decision

Here we will use GitHub flow, and promote (but not mandate) GitHub flow to downstream users of the template.

## Consequences

GitHub flow is a simple branching strategy that encourages small, incremental changes and continuous integration.

For projects requiring more governance on their releases, they should create an adr and change their CONTRIBUTING.md to reflect their branching strategy.
